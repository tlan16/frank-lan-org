property.com.au: a property research website relaunched in 2022 with around 15 million searchable Australian addresses, including sales and rental histories. My team built its web frontend and backend APIs from scratch using TypeScript, React, Node.js, GraphQL, PostgreSQL/PostGIS and AWS (ECS, CloudFront).

Aerial imagery pipeline for property.com.au: concurrent, queue-driven image processing with production workers configured to auto-scale from zero to many ECS tasks. I built the image processing, scheduling, data integration and delivery infrastructure, with LocalStack emulating AWS services for cloud-free local development. Built with TypeScript, Node.js, Sharp, Docker and AWS (ECS Fargate, SQS, S3, DynamoDB, CloudFront).

Member accounts and authentication for property.com.au: supporting over 43,000 monthly active members (May 2026). I built sign-in and token handling, profile management, recent searches, followed properties and account deletion. Built with TypeScript, Node.js, GraphQL, Auth0 (OAuth 2.0/OpenID Connect), Aurora PostgreSQL and AWS ECS Fargate.
