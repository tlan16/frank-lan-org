property.com.au: a property research website covering around 15 million properties across Australia, including sales and rental histories. My team built its web frontend and backend APIs from scratch using TypeScript, React, Node.js, GraphQL, PostgreSQL/PostGIS and AWS (ECS, CloudFront).

Aerial imagery pipeline for property.com.au: processes and publishes aerial photographs for property research. I contributed to image processing, task scheduling, data integration and delivery infrastructure. Built with TypeScript, Node.js, Sharp and AWS (ECS Fargate, SQS, S3, DynamoDB, CloudFront).

Member accounts and authentication for property.com.au: sign-in, profile management and account lifecycle services. I contributed to authentication and token handling, recent searches, followed properties and account deletion. Built with TypeScript, Node.js, GraphQL, Auth0 (OAuth 2.0/OpenID Connect), Aurora PostgreSQL and AWS ECS Fargate.
